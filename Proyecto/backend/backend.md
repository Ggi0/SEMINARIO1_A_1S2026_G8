

## para iniciar el backend
* `npm init -y`

## en el package.json agregar:

```json
"scripts": {
    "start": "node index.js",      <--------- para iniciar el proyecto
    "test": "echo \"Error: no test specified\" && exit 1"
  },
```

## instalar express
* `npm install express`

## instalar los cors
* `npm install cors`

## instalar Dotenv
* `npm install dotenv`

## instalar mysql2
* `npm install mysql2`

---

## intalacions para cognito y rekognition
* `npm install @aws-sdk/client-cognito-identity-provider @aws-sdk/client-rekognition amazon-cognito-identity-js jsonwebtoken jwks-rsa`
